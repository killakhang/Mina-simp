# Simulation model

Mina Sim keeps observable state separate from generated dialogue. A future model provider proposes dialogue/actions; evaluators update explicit state and telemetry records why a score changed.

Signals are heuristic and configurable. They should never be presented as objective measurements of a real person's hidden thoughts. Rejection, boundaries, disengagement, and incompatible preferences are normal simulation outcomes.

A healthy-boundary policy should prioritize clear limits and disengagement over retaliatory toxicity. Alternate fictional personality states can be explored as simulation parameters without treating harmful behavior as optimal dating strategy.
